PRIVATE CREATOR TOOL / API CLIENT

Owner-approved publishing for original music videos.

Yohaku Spark Uploader is a private, single-user command‑line application operated by the owner of the Yohaku Spark channel. It handles only creator-owned music, lyrics, artwork, and video.

EXACT API USE

  • Upload an owner-selected MP4 as private
  • Set metadata and a custom thumbnail
  • Optionally add the video to an owner-selected playlist
  • Read processing and visibility status back from the API
  • Publish only after a separate owner approval

Requested OAuth scopes

youtube.upload
youtube.force-ssl
Not a public service. The client is not sold, distributed, or offered to third parties. It is not affiliated with or endorsed by YouTube or Google.

CONTROLLED WORKFLOW

Two explicit approval gates

  1. 01

    Validate locally

    Verify the MP4, thumbnail, title, description, tags, audience designation, and synthetic-media disclosure before any API write.

  2. 02

    Approve private upload

    An explicit confirmation is required. Every initial upload is private.

  3. 03

    Read back exact state

    Set the custom thumbnail, optionally add an owner-selected playlist, then verify processing and privacy status through the API.

  4. 04

    Approve publication separately

    Public, unlisted, or scheduled publication requires a second explicit confirmation followed by another API readback.

DATA MINIMIZATION

Only what the workflow needs

The client stores local OAuth credentials, upload manifests, resulting video or playlist item IDs, operation timestamps, and verification receipts. It does not collect comments, analytics, search results, or third-party viewer data.
