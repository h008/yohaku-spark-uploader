Privacy Policy

This policy describes how Yohaku Spark Uploader uses information received through Google OAuth and the YouTube Data API.

1. Application scope

Yohaku Spark Uploader is a private command-line tool used only by the owner of the Yohaku Spark channel. It is not available to the public and does not support third-party accounts.

2. Google and YouTube data accessed

After the owner grants OAuth consent, the application can identify the authenticated channel and perform owner-requested operations on that channel:

  • upload creator-owned videos;
  • read and update the status and metadata of those uploads;
  • set custom thumbnails;
  • add uploaded videos to owner-selected playlists; and
  • read back upload, processing, privacy, thumbnail, and playlist state for verification.

The requested scopes are https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.force-ssl.

3. Data stored

The application stores the minimum data needed to operate and verify uploads:

  • OAuth client credentials and the owner's refresh token;
  • local upload manifests supplied by the owner;
  • YouTube video IDs and playlist item IDs returned by the API;
  • operation timestamps; and
  • API readback receipts that confirm processing and privacy status.

OAuth credentials are stored only on the owner's private server with restricted file permissions. They are never committed to a public repository, placed in synchronized notes, or sent to another service.

4. Data not collected

The application does not collect or retain viewer data, search history, comments, subscriber lists, analytics, advertising data, or data from third-party channels. It does not create derived metrics or profiles.

5. Sharing and sale

No Google user data is sold, rented, shared, or transferred to third parties. Data is used only to carry out operations explicitly requested by the authenticated channel owner.

6. Retention and deletion

The OAuth token is retained until the owner revokes access or deletes the local token file. Upload manifests and verification receipts remain under the owner's control and can be deleted at any time. The application does not maintain a remote user database.

7. Revoking access

The owner can revoke access from Google Account third-party connections. After revocation, the local OAuth token can be deleted from the private server. Revocation prevents further API access unless the owner completes OAuth consent again.

8. Security

Credentials are protected by local operating-system permissions, least-privilege OAuth scopes, explicit write confirmations, private-first uploads, and post-write API verification. Publication uses a separate approval command.

9. Google API Services policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The application also follows the YouTube API Services Terms of Service and YouTube API Services Developer Policies. Google's handling of information is described in the Google Privacy Policy.

10. Contact

Privacy questions can be submitted through the project's public issue tracker. Do not include passwords, OAuth codes, access tokens, or other secrets.
